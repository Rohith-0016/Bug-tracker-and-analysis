# Bug Tracker and Analysis

This project is a basic bug tracking and analysis system built using Python. The idea is to work with bug data and understand how issues are distributed, how long they take to resolve, and how they change over time.

## About the Project
In real projects, bugs are constantly reported and fixed. This project takes a small dataset of bugs and analyzes it to get useful insights like severity distribution, status, and resolution time.

## What I did
- Created a dataset of bugs with details like severity, status, and dates  
- Cleaned and processed the data using Pandas  
- Calculated how long each bug took to resolve  
- Analyzed how many bugs fall under each severity  
- Checked how bugs are changing week by week  
- Plotted simple graphs for better understanding  

## Tools Used
- Python  
- Pandas  
- Matplotlib  
- Jupyter Notebook
